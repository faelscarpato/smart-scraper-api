# Smart Scraper API

Quero que crie um backend que deve rodar em cmd, PowerShell, bash... Esse backend deve ser uma API de scraping de web, mas o principal objetivo é conseguir fazer busca primeiro e aí fazer reconhecimento dos links dos resultados da busca e aí bater com o que o usuário pediu vs os resultados e o que mais se aproximar ou ter palavras chaves aí sim a API deverá abrir o link ou os links e fazer webscraping.
